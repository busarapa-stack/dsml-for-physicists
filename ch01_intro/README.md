# บทที่ 1 บทนำ: โค้ดประกอบ

> เลข **โค้ดที่ N.M** ในเอกสารนี้ตรงกับเลขที่พิมพ์ในตำรา ส่วนชื่อในวงเล็บ เช่น `code:xxx` เป็นชื่ออ้างอิงภายในของต้นฉบับ LaTeX ใช้ค้นในไฟล์สคริปต์ได้

บทที่ 1 เป็นบทแนวคิด ตัวอย่างโค้ดทั้งสี่ในตำรา (`code:root-tree`, โค้ดที่ 1.2 (`code:ligo-hdf5`), โค้ดที่ 1.3 (`code:fits-header`), โค้ดที่ 1.4 (`code:matproj-json`)) แสดงเพียงโครงสร้างของไฟล์ ไม่ได้เป็นโค้ดที่รันได้ โฟลเดอร์นี้จึงเติมส่วนที่ขาด คือสร้างไฟล์ตัวอย่างขนาดเล็กในทั้งสี่รูปแบบ แล้วเปิดดูโครงสร้างจริงด้วย Python ผู้อ่านจะเห็นกับตาว่า Tree ของ ROOT, กลุ่มของ HDF5, ส่วนหัวของ FITS และการซ้อนชั้นของ JSON มีหน้าตาอย่างไร โดยไม่ต้องดาวน์โหลดไฟล์ขนาดหลายกิกะไบต์

ไฟล์ทุกไฟล์ใน `data/` เป็น **ข้อมูลจำลอง** ที่เลียนแบบโครงสร้างของข้อมูลจริง ชื่อและคำอธิบายในไฟล์ระบุคำว่า SYNTHETIC ไว้ทุกไฟล์ เพื่อไม่ให้สับสนกับข้อมูลจริง

## ผลที่ควรได้

ผลลัพธ์เต็มอยู่ใน `expected_output.txt` ตัวเลขสำคัญที่ตรงกับตำรา ได้แก่

- ไฟล์ strain มี 131,072 จุด เท่ากับ 32 วินาที × 4096 Hz
- ΔL = 10⁻²¹ × 4000 m = 4 × 10⁻¹⁸ m เล็กกว่าเส้นผ่านศูนย์กลางโปรตอน 250 เท่า ("หลายร้อยเท่า" ในตำรา)
- ระยะเพื่อนบ้านใกล้สุดของ Si เท่ากับ 2.352 Å และทุกอะตอมมีเพื่อนบ้าน 4 ตัว

ตัวเลขอื่นในไฟล์ เช่น จำนวนเหตุการณ์ในแต่ละค่า nMuon เป็นผลของข้อมูลจำลองที่กำหนด `SEED = 2026` ไว้ ผู้อ่านทุกคนจะได้ค่าเดียวกัน

รูปที่สร้างใน `outputs/`:

- `ch01_dimuon_mass.png` ฮิสโทแกรมมวลยังผลของมิวออนคู่
- `ch01_strain.png` อนุกรมเวลา strain และภาพขยายช่วงที่มีสัญญาณจำลอง
- `ch01_fits_image_spectrum.png` ภาพกาแล็กซีและสเปกตรัมดาวฤกษ์จำลอง

## ข้อควรรู้เกี่ยวกับ `optional/fetch_real_data.py`

ต้องต่ออินเทอร์เน็ตและติดตั้งแพ็กเกจเพิ่ม `pip install gwosc mp-api aiohttp requests` ส่วน Materials Project ต้องสมัครรับ API key ฟรี แล้วตั้งค่าในหน้าต่าง Terminal ก่อนรันด้วยคำสั่ง `export MP_API_KEY="..."` ห้ามเขียนรหัสนี้ลงในไฟล์ใดของโฟลเดอร์ตำรา

```bash
python optional/fetch_real_data.py            # ทุกส่วน
python optional/fetch_real_data.py cms        # เลือกเฉพาะส่วน
python optional/fetch_real_data.py cmsplot    # วาดกราฟจากผลของ cms โดยไม่ต้องต่อเน็ต
python optional/check_real_vs_book.py         # เทียบไฟล์จริงกับข้อความในตำรา (ไม่ต้องต่อเน็ต)
```

ผลจากการทดสอบกับข้อมูลจริงเมื่อ 26 ก.ย. 2569 บันทึกไว้ใน `optional/expected_output_real.txt` ทุกส่วนทำงานถูกต้อง และ `check_real_vs_book.py` ผ่านครบ 13 ข้อ

- **LIGO** GWOSC ให้ไฟล์ช่วงยาว 4096 วินาทีของรอบสังเกตการณ์ O1 (16,777,216 จุด ขนาดเกิน 100 MB) ไม่ใช่ไฟล์ 32 วินาทีตามตัวอย่างในตำรา แต่โครงสร้างกลุ่ม `meta`, `strain` และ `quality` ตรงกับโค้ดที่ 1.2 (`code:ligo-hdf5`) สคริปต์ตัดช่วง 32 วินาทีเริ่มที่ GPS 1126259446 ได้ 131,072 จุดตรงตามตำรา ค่า strain สูงสุดคือ 7.1 × 10⁻¹⁸ มากกว่าสัญญาณ 10⁻²¹ หลายพันเท่า เพราะสัญญาณรบกวนความถี่ต่ำครอบงำ
- **CMS** โครงสร้าง Tree ของไฟล์จริงตรงกับโค้ดที่ 1.1 (`code:root-tree`) ในตำราทุก Branch ใน 100,000 เหตุการณ์แรกมีคู่มิวออนประจุตรงข้าม 37,183 คู่ กราฟแกนลอการิทึมจาก `cmsplot` แสดงยอดของ J/ψ (3,623 คู่ในช่วง 2.9–3.3 GeV), Υ(1S) (510 คู่ในช่วง 9.2–9.7 GeV) และ Z (6,846 คู่ในช่วง 81–101 GeV)
- **Materials Project** ช่องว่างแถบพลังงานของ Si ที่คำนวณด้วย GGA คือ 0.610 eV ขณะที่ค่าจากการทดลองคือ 1.12 eV ต่ำกว่าราวร้อยละ 46 ซึ่งสอดคล้องกับข้อความในกล่องความเข้าใจคลาดเคลื่อนของหัวข้อ `sssec:matproj` ส่วนความหนาแน่น 2.313 g/cm³ ต่ำกว่าค่าจากการทดลอง (2.329 g/cm³) ไม่ถึงร้อยละ 1 เพราะ GGA ให้ค่าคงที่แลตทิซ 5.444 Å ยาวกว่าค่าจริง (5.431 Å) ร้อยละ 0.23 ความคลาดเคลื่อนเชิงระบบจึงไม่ได้ใหญ่เท่ากันทุกสมบัติ ความหนาแน่นที่คำนวณกลับจากไฟล์ CIF ตรงกับค่าในฐานข้อมูลทุกหลัก แสดงว่าข้อมูลสองส่วนนี้สอดคล้องกันเอง

ค่าจากบริการออนไลน์อาจเปลี่ยนเมื่อผู้ให้บริการปรับปรุงฐานข้อมูล ตัวเลขทุกค่าในตำราและใน `expected_output.txt` มาจากข้อมูลจำลองของ `01_make_sample_files.py` จึงไม่ขึ้นกับสคริปต์นี้

strain จริงของ GW150914 มีค่าสูงสุดมากกว่า 10⁻²¹ มาก เพราะสัญญาณรบกวนความถี่ต่ำครอบงำอยู่ สัญญาณคลื่นความโน้มถ่วงจะปรากฏหลังผ่านการทำให้ขาว (whitening) และกรองแถบความถี่ ซึ่งเรียนในบทที่ 4

## แบบฝึกหัดต่อยอด

1. แก้ `SEED` ใน `01_make_sample_files.py` แล้วรันใหม่ จำนวนเหตุการณ์ในแต่ละค่า nMuon เปลี่ยนไปเท่าใด ตำแหน่งยอดของ Z เปลี่ยนหรือไม่ และเพราะเหตุใด
2. ใน `02_inspect_root.py` วิธี (a) ตัดมิวออนตัวที่สามทิ้ง ถ้ามิวออนที่ถูกตัดทิ้งเป็นตัวที่มาจาก Z จริง การวิเคราะห์จะผิดอย่างไร ลองเรียงมิวออนตาม pT ก่อนตัด แล้วเปรียบเทียบผล
3. ใน `06_crystal_graph.py` ลองเพิ่มค่า `cutoff` ให้ครอบคลุมเปลือกที่สอง จำนวนเพื่อนบ้านต่ออะตอมกลายเป็นเท่าใด (คำตอบตามโครงสร้างเพชรคือ 4 + 12 = 16)

## บันทึกการตรวจสอบความสอดคล้องกับตำรา (26 ก.ย. 2569)

การเปิดไฟล์จริงของ LIGO พบว่ากลุ่ม `meta` ไม่มีรายการ `SampleRate` ตามที่โค้ดที่ 1.2 (`code:ligo-hdf5`) ฉบับก่อนหน้าแสดงไว้ อัตราสุ่มตัวอย่างเก็บเป็นคุณลักษณะ `Xspacing` ของชุดข้อมูล `strain/Strain` และกลุ่ม `quality` มีกลุ่มย่อย `simple` เพิ่มจาก `injections` จึงแก้ทั้งตัวอย่างโค้ดและย่อหน้าบรรยายในตำรา แก้ไฟล์จำลองให้มีโครงสร้างเหมือนไฟล์จริง และแก้ `03_inspect_hdf5.py` ให้อ่านอัตราสุ่มตัวอย่างจาก `Xspacing`

ขนาดไฟล์ Galaxy10 DECaLS ในบทที่ 1 เดิมเขียน 2.5 กิกะไบต์ ขัดกับบทที่ 11 ซึ่งเขียน 2.7 GB จึงแก้บทที่ 1 ให้ตรงกับบทที่ 11

ไฟล์ ROOT จำลองเปลี่ยนตัวแปรจลนศาสตร์ของมิวออนเป็นชนิด `float` (32 บิต) และเรียงลำดับ Branch เหมือนไฟล์จริงของ CMS

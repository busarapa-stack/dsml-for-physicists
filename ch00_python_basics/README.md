# บทที่ 0 พื้นฐานการเขียนโปรแกรมภาษาไพทอนสำหรับนักฟิสิกส์: โค้ดประกอบ

> เลข **โค้ดที่ N.M** ในเอกสารนี้ตรงกับเลขที่พิมพ์ในตำรา ส่วนชื่อในวงเล็บ เช่น `code:xxx` เป็นชื่ออ้างอิงภายในของต้นฉบับ LaTeX ใช้ค้นในไฟล์สคริปต์ได้

บทที่ 0 เป็นบทปูพื้นฐาน ตัวอย่างโค้ดทั้ง 15 ชิ้นในตำรารันได้ทันที และคัดลอกลงในสคริปต์ทุกบรรทัด ตัวอย่างหลักคือการหาค่า g จากลูกตุ้มอย่างง่าย ข้อมูลลูกตุ้มใน `data/pendulum.csv` เป็น **ข้อมูลจำลอง** ที่สร้างด้วย `01_make_pendulum_data.py` จาก g = 9.78 m/s² และความคลาดเคลื่อนจากการจับเวลาสิบรอบด้วยมือ (ส่วนเบี่ยงเบนมาตรฐาน 0.15 s ต่อครั้ง, SEED = 2028) seed นี้เลือกเพราะให้ชุดข้อมูลแบบกรณีทั่วไป ส่วน SEED = 2026 ให้ g จากความชันเท่ากับ 9.63 m/s² ห่างจากค่าจริงราวสามเท่าของความไม่แน่นอน ซึ่งเป็นการสุ่มที่ไม่ปกติและจะทำให้ผู้เรียนบทแรกสับสน เหตุผลนี้บันทึกไว้ใน docstring ของ `01_make_pendulum_data.py` ด้วย ผู้สอนแทนด้วยไฟล์ข้อมูลจากปฏิบัติการจริงที่มีสามคอลัมน์ `L_m, trial, t10_s` ได้โดยไม่ต้องแก้โค้ด

สำหรับชั้นเรียน ใช้ `notebooks/ch00_python_basics_classroom.ipynb` ซึ่งรันได้ทันทีบน Colab ด้วยไฟล์เดียว แบ่งโค้ดเป็นเซลล์เล็ก และมีแบบฝึกพร้อมเซลล์ตรวจคำตอบ

## ข้อสังเกตจากการรันที่ใช้สอนได้

**ช่วงความเชื่อมั่นที่ไม่ครอบค่าจริง:** ข้อมูลสปริงให้ k = 5.17 ± 0.07 N/m ซึ่งค่าจริง 5.0 N/m อยู่นอกช่วงร้อยละ 95 ตำราใช้ผลนี้อธิบายความหมายของช่วงความเชื่อมั่นโดยตั้งใจ สคริปต์ `01_hooke_ols.py` ทดลองซ้ำด้วยเมล็ดสุ่มอื่น 2,000 ครั้ง ช่วงไม่ครอบค่าจริง 0.052 ของครั้ง ตรงกับร้อยละ 5 ที่ควรเป็น

**χ²_red = 1.19 จากแบบจำลองที่ถูกต้อง:** ข้อมูลออสซิลเลเตอร์สร้างจากแบบจำลองและ σ ที่ถูกต้องทุกประการ แต่ได้ p = 0.035 ตำราใช้ผลนี้เตือนว่าต้องอ่าน χ²_red คู่กับภาพส่วนเหลือ

**การถ่วงน้ำหนัก:** `05_shockley_diode.py` เพิ่มการปรับแบบไม่ถ่วงน้ำหนักให้เทียบ ได้ n = 1.72 ซึ่งผิดไปมาก เพราะจุดที่แรงดันสูงซึ่งกระแสใหญ่กว่าจุดแรกหลายหมื่นเท่ากำหนดผลเกือบทั้งหมด

## บันทึกการตรวจสอบความสอดคล้องกับตำรา (26 ก.ย. 2569)

ตัวเลขในเนื้อหาหลักของบทที่ 5 ตรงกับผลการรันทุกค่า รวมถึงตัวเลขในคำถามทบทวน (0.2/0.03 ≈ 6.7, √(2/10) = 0.45, √(2/1000) = 0.045) แก้ข้อความในตำราสองจุด ทั้งคู่อยู่ในแนวคำตอบ

1. **แนวคำตอบ E5.5:** Q = 10.5 ± 0.3 ห่างจากค่าจริง 10.0 ราว 1.8σ ไม่ใช่ 1.9σ (ตัวเลข 1.9σ เป็นของ γ)
2. **แนวคำตอบ E5.6:** เดิมเขียน χ²_red ≈ 5.4, ส่วนเหลือต่ำสุดราว −9σ และ n ≈ 1.45 ซึ่งทำซ้ำไม่ได้ ข้อมูลที่สร้างตามเงื่อนไขในตำรา (เมล็ดสุ่ม 2026 และความไม่แน่นอนร้อยละ 5 ของกระแสที่วัด ตามโค้ดที่ 5.7 (`code:shockley-cf`)) ให้ 5.2, −7σ และ 1.44 จึงแก้ตัวเลข และเพิ่มผลของแบบจำลองที่มี R_s (R_s = 19 ± 2 Ω, χ²_red ≈ 0.7) คู่มือผู้สอนแก้ตามและชี้ไปที่สคริปต์ที่สร้างข้อมูลชุดนี้

## การตรวจรอบที่สอง (26 ก.ย. 2569)

- นำตัวอย่างโค้ดทั้ง 8 ชิ้นจากไฟล์ตำรามาต่อกันตามลำดับในตำรา แล้วรันรวดเดียวเหมือนผู้อ่านที่พิมพ์ตามใน notebook เดียว ทุกชิ้นรันผ่าน และให้ตัวเลขเดียวกับสคริปต์แยก (ชื่อ `popt_d`, `pcov_d` ของไดโอดไม่ทับ `pcov` ที่ โค้ดที่ 5.8 (`code:q-prop`) ใช้)
- เพิ่ม `07_claims_checks.py` ตรวจข้อความในเนื้อหาที่ไม่มีตัวอย่างโค้ดของตัวเอง
- แก้ข้อความในตำราสองจุด
  1. **ภาวะร่วมเส้นตรงพหุ:** ตำรายกตัวอย่าง "x กับ x³ เมื่อ x เป็นบวกทั้งหมด" แต่ x กับ x³ สัมพันธ์กันราว 0.92 ไม่ว่า x จะเป็นบวกหรือไม่ และการปรับมาตรฐานก่อนก็ไม่ช่วย คู่ที่ตรงกับข้อความคือ x กับ x² (0.97, VIF 15) ซึ่งการปรับมาตรฐานทำให้สหสัมพันธ์หายไป จึงเปลี่ยนตัวอย่าง และเพิ่มตัวเลข VIF และข้อสังเกตเรื่อง z กับ z³
  2. **เส้นโค้งการตรวจสอบไขว้:** ตำราเขียนว่าได้ "เส้นโค้งรูปตัวยู" แต่กราฟที่ผู้อ่านจะเห็นมีโหนกที่ λ ≈ 4×10⁻⁴ เพิ่มประโยคอธิบายสาเหตุ (ส่วนหนึ่งต้องประมาณนอกช่วง) และค่าที่ λ = 0 ซึ่งเชื่อมกับกล่องความเข้าใจคลาดเคลื่อนเรื่องการประมาณนอกช่วงที่ตามมา

# บทที่ 2 การโปรแกรมเชิงวิทยาศาสตร์และการทำงานที่ทำซ้ำได้: โค้ดประกอบ

> เลข **โค้ดที่ N.M** ในเอกสารนี้ตรงกับเลขที่พิมพ์ในตำรา ส่วนชื่อในวงเล็บ เช่น `code:xxx` เป็นชื่ออ้างอิงภายในของต้นฉบับ LaTeX ใช้ค้นในไฟล์สคริปต์ได้

ตัวอย่างโค้ดในบทที่ 2 ส่วนใหญ่เป็นโค้ดที่รันได้อยู่แล้ว แต่หลายชิ้นในตำราแสดงเพียงบางส่วน เช่น ตัวอย่างแถบความคลาดเคลื่อนที่ใช้ตัวแปร `t_obs` และ `x_obs` โดยไม่ได้บอกว่าสร้างมาอย่างไร โฟลเดอร์นี้เติมส่วนที่ขาดให้รันได้ครบ และตรวจตัวเลขทุกค่าที่ตำรากล่าวถึงกับผลการรันจริง

ออสซิลเลเตอร์ฮาร์มอนิกซึ่งใช้ในหลายสคริปต์เก็บไว้ในไฟล์ `oscillator.py` ไฟล์เดียว ทุกสคริปต์จึงใช้แบบจำลองชุดเดียวกัน

## ผลที่ควรได้

ผลเต็มอยู่ใน `expected_output.txt` ตัวเลขที่ตรงกับตำรา ได้แก่

- R(45°) = 40.79 m
- พลังงานของกรณีไม่มีความหน่วงคลาดราว 3 × 10⁻⁸ เมื่อใช้ `rtol=1e-9`
- γ ที่ได้จากการปรับเส้นโค้งคือ 0.1001
- ค่าตั้งต้นของ `solve_ivp` ทำให้พลังงานแกว่งราวร้อยละ 0.35 ใน 20 คาบ
- ระยะตกเมื่อมีแรงต้านคือ 34.1 m

ตัวเลขสองกลุ่มที่ขึ้นกับเครื่อง ได้แก่เวลาที่ใช้ใน `02_vectorization.py` (เครื่องที่ใช้จัดทำตำราเร็วขึ้นราว 30–50 เท่า แล้วแต่รอบ ตรงกับ "หลายสิบถึงหลายร้อยเท่า" ในตำรา) และคอลัมน์เวลาใน `E2_3_rtol.py`

`08_figures.py` นับว่ามีจุดวัดกี่จุดใน 21 จุดที่อยู่ในช่วง ±1σ จากเส้นทฤษฎี ได้ 18 จุด ขณะที่ค่าคาดหมายคือ 14 ± 2 จุด ผลนี้เป็นความผันผวนตามธรรมชาติของข้อมูลจำนวนน้อย ไม่ได้เลือก seed ให้ได้ค่านี้ ใช้เป็นตัวอย่างอภิปรายได้ว่าข้อมูล 21 จุดบอกอะไรเกี่ยวกับขนาดของแถบความคลาดเคลื่อนได้ไม่มากนัก

## บันทึกการตรวจสอบความสอดคล้องกับตำรา (26 ก.ย. 2569)

การรันจริงยืนยันตัวเลขส่วนใหญ่ในบทที่ 2 จึงแก้ข้อความในตำราเพื่อให้ตรงกับผลที่ผู้อ่านจะเห็นบนหน้าจอดังนี้

- หัวข้อการตรวจพลังงาน: เดิมเขียนว่า γ "อยู่ที่ประมาณ 0.100" แต่โค้ดในตำราพิมพ์ทศนิยมสี่ตำแหน่ง ผู้อ่านจะเห็น 0.1001 จึงแก้ให้ตรงกับที่พิมพ์ และระบุความคลาดเคลื่อนของพลังงานเป็น 3 × 10⁻⁸
- กล่องความเข้าใจคลาดเคลื่อนเรื่องค่าตั้งต้นของ `solve_ivp`: แก้ "ราวร้อยละ 0.3" เป็น "ราวร้อยละ 0.35" ตามผลที่วัดได้
- แนวคำตอบ E2.3: เพิ่มตัวเลขความคลาดเคลื่อนของ rtol ทั้งสามค่าจากการทดลองจริง
- แนวคำตอบ E2.4: เดิมเขียน "ร้อยละหนึ่งถึงสอง" แต่ γ = 0.5 ให้ร้อยละ 2.3 จึงแก้เป็นตัวเลขที่วัดได้ คือร้อยละ 2.3 และ 1.4

## การตรวจรอบที่สอง (26 ก.ย. 2569)

- เทียบตัวอย่างโค้ดทั้ง 21 ชิ้นในตำรากับสคริปต์ทีละบรรทัด สคริปต์ที่เคยจัดโค้ดใหม่ (`06_oscillator_energy.py`, `02_vectorization.py`, `09_random_seed.py`) ปรับให้มีโค้ดตามตำราทุกบรรทัด ส่วนที่ต่างเหลือเพียงเครื่องหมาย `$` และ `(.venv) $` ที่ตำราใช้แสดงพรอมต์ของเทอร์มินัล และการบันทึกภาพลงโฟลเดอร์ `outputs/`
- ตำราเขียนว่า RK45 เป็นวิธีอันดับ 4(5) แต่เอกสารของ SciPy ระบุว่าเป็นวิธี Dormand–Prince อันดับ 5(4) คือก้าวด้วยสูตรอันดับห้าและประมาณความคลาดเคลื่อนด้วยอันดับสี่ จึงแก้ในตำรา
- เพิ่มย่อหน้าในหัวข้อสภาพแวดล้อมเสมือน อธิบายกรณีที่เครื่องมีแต่คำสั่ง `python3` และข้อความ `externally-managed-environment` ที่เกิดเมื่อสั่ง `pip install` นอกสภาพแวดล้อมเสมือนบน macOS ที่ติดตั้ง Python ผ่าน Homebrew ปัญหานี้พบจริงระหว่างทดสอบโค้ดชุดนี้

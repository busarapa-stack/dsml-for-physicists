# ข้อมูล SDSS จริงสำหรับกรณีศึกษาในหัวข้อ 6.5

ตำราใช้ตาราง 100,000 วัตถุที่คัดจาก SDSS DR17 ซึ่งเผยแพร่บน Kaggle ในชื่อ *Stellar Classification Dataset – SDSS17* (fedesoriano) ถ้ายังไม่มีไฟล์นี้ `05_sdss_data.py` จะสร้าง **ข้อมูลจำลองแทน (synthetic stand-in)** ที่มีหลักและจำนวนแต่ละประเภทเท่าของจริง เพื่อให้สคริปต์ทุกตัวรันได้ ตัวเลขที่ได้จากข้อมูลจำลองนี้ **ไม่ใช่ผลของท้องฟ้าจริง**

## วิธีที่ 1: ดาวน์โหลดจาก Kaggle (ตรงกับตำราที่สุด)

1. เข้า https://www.kaggle.com/datasets/fedesoriano/stellar-classification-dataset-sdss17 (ต้องมีบัญชี Kaggle)
2. กด Download แล้วแตกไฟล์ zip จะได้ `star_classification.csv`
3. วางไฟล์ไว้ที่ `ch06_classification/data/raw/star_classification.csv` ทับไฟล์จำลองได้เลย
4. รัน `python run_chapter.py ch06_classification --with-exercises` สคริปต์จะรู้เองว่าเป็นไฟล์จริง (มีหลัก `spec_obj_ID`) และไม่เขียนทับ

## วิธีที่ 2: ดึงจาก SkyServer ของ SDSS โดยตรง

```bash
cd code/ch06_classification
python optional/fetch_sdss_skyserver.py
```

สคริปต์ส่งคำสั่ง SQL ไปยัง SkyServer DR17 และดึงวัตถุที่มีสเปกตรัมตามจำนวนของแต่ละประเภทเท่ากับไฟล์ Kaggle เกณฑ์การคัดเลือกไม่เหมือนไฟล์ Kaggle ทุกประการ ตัวเลขจึงต่างกันเล็กน้อย

## สิ่งที่ต้องตรวจเมื่อได้ข้อมูลจริง

ข้อความในตำราหัวข้อ 6.5 และแนวคำตอบ E6.5 ที่ต้องยืนยันด้วยข้อมูลจริง (ข้อมูลจำลองยืนยันไม่ได้)

- วิธีไม่เชิงเส้น โดยเฉพาะป่าสุ่ม ได้ macro-F1 สูงมากเมื่อใช้เรดชิฟต์
- เรดชิฟต์เป็นลักษณะเด่นอันดับแรก ตามด้วยดัชนีสีที่เกี่ยวกับแถบ u และ g
- เมื่อตัดเรดชิฟต์ออก macro-F1 ลดลง และความสับสนส่วนใหญ่อยู่ระหว่างดาวฤกษ์กับเควซาร์
- ดัชนีสี u − g และ g − r ขึ้นมาเป็นลักษณะเด่นสำคัญเมื่อไม่มีเรดชิฟต์

ผลของ `07_sdss_compare.py` พิมพ์ทุกข้อนี้ไว้แล้ว ส่งผลที่ได้กลับมาเพื่อตรวจเทียบกับตำรา
